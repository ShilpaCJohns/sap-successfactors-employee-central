# SAP SuccessFactors Employee Central — Practice Portfolio

## Project Overview

This repository showcases my hands-on learning and configuration practice in SAP SuccessFactors Employee Central using **Novocare Technologies**, a fictional organization created for demonstration purposes.

With a background in HR operations, I am developing practical skills in HR technology, employee data management, system configuration, and HR process automation.

## Project Objectives

- Understand SAP SuccessFactors Employee Central data model architecture.
- Configure and document foundation objects and picklists.
- Explore MDF custom objects, fields, and associations.
- Practice business rules and workflow configuration.
- Understand Role-Based Permissions (RBP) and access management.
- Document configuration and testing concepts.

## Key Configuration Areas

### 1. Data Model Architecture
Corporate Data Model, Country-Specific Corporate Data Model, and related configuration concepts.

### 2. Foundation Objects and Picklists
Organizational structure, including Legal Entity, Business Unit, Division, Department, Location, and Cost Centre.

### 3. MDF Configuration
Custom object creation, field configuration, and associations.

### 4. Business Rules and Automation
Exploration of business logic, rule scenarios, and automation in Employee Central.

### 5. Workflows and Approval Governance
Workflow configuration concepts and approval processes.

### 6. Role-Based Permissions (RBP)
Permission roles, access management, and security configuration concepts.

### 7. Testing and Validation
Documentation of configuration checks and testing concepts relevant to Employee Central.
